CPS IE Studioหลังบ้าน · ผู้ดูแลระบบ
เปิดแอปผู้ใช้ →

หน้านี้สำหรับผู้ดูแลระบบคนเดียว ไม่มีลิงก์จากแอปผู้ใช้ อย่าส่งที่อยู่หน้านี้ให้คนอื่น

1. เชื่อมข้อมูลกลาง (Google Sheet)

ส่ง “ลิงก์สำหรับทีม” ให้ผู้ใช้เปิดครั้งแรกครั้งเดียว เครื่องนั้นจะเชื่อมข้อมูลกลางเอง และซิงค์อัตโนมัติทุก 30 วินาที

2. เข้าสู่ระบบผู้ดูแล

รหัสผู้ดูแลตั้งได้ที่ Apps Script → ⚙ Project Settings → Script properties → ชื่อ ADMIN_CODE (ตั้งครั้งเดียว ไม่ต้อง Deploy ใหม่) · หน้านี้จะออกจากระบบเองเมื่อปิดแท็บ

3. รหัสเข้าใช้งานของทีม

ผู้ใช้ทุกคนต้องใส่รหัสนี้ครั้งแรกในแต่ละเครื่อง · เปลี่ยนรหัส = ทุกเครื่องต้องใส่รหัสใหม่ · ส่งรหัสให้ทีมทางช่องทางภายใน แยกจากลิงก์สำหรับทีม

4. ข้อมูลใน Sheet

5. PIN ผู้อนุมัติ (ต่อฝ่าย)

PIN เก็บที่ server (Script Properties ของ Apps Script) ไม่อยู่ใน Sheet และไม่ถูกส่งกลับมาแสดง · ใช้อนุมัติได้ทุกเครื่อง · ช่องที่เว้นว่าง = ไม่เปลี่ยน · ใส่ PIN ผิด 5 ครั้ง ฝ่ายนั้นล็อก 10 นาที

6. ข้อมูลสำรอง

นำเข้า = เพิ่ม/อัปเดตรายการตาม id ขึ้น Sheet (ไม่ลบของเดิม) ทุกเครื่องจะได้รับในการซิงค์รอบถัดไป
